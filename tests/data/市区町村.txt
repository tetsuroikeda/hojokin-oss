# 出典: https://ja.wikipedia.org/wiki/日本の地方公共団体一覧 （見た日 2026-11-05）
# 形: 1行に1件。タブ区切りで「都道府県<TAB>名前<TAB>種類<TAB>親の市」。種類は 市・町・村・特別区・政令指定都市の区 のどれか。
# 名前には郡の名前と読みを付けない。政令指定都市の区は区の名前だけを書き、4つ目の欄に親の市を書く。ほかの行の4つ目の欄は空。
# 並びは都道府県の順（北海道から沖縄県）。その中は出典の並びのまま（政令指定都市の行のすぐ後にその区を置く）。
# 字は出典のとおり（ヶ と ケ の別、飛驒市・檮原町 など。飛驒市は 飛騨市、檮原町は 梼原町 とも書く）。北方領土の6村は入れない。
# 数: 市 792、町 743、村 183（合わせて 1,718）、特別区 23、政令指定都市の区 171（20市）。合わせて 1,912 行。
# 都道府県ごとの市・町・村の数は https://ja.wikipedia.org/wiki/市町村 の表（2023年3月現在。その後2026年11月までに市町村の数の変わりはない）と照らし、47都道府県すべてで合う。全国の数は https://www.soumu.go.jp/kouiki/kouiki.html と合う。
