# 実験 E4 の手順（作者と一緒に）

DESIGN 13.2 の E4 を確かめます。確かめるのは次の3つです。

- デスクトップアプリで、プラグインを入れられるか（「＋」→ Add plugins）
- SessionStart・UserPromptSubmit・PreToolUse・Stop の hook が動くか。PreToolUse で拒めるか（default モードと auto モードの両方で）
- 開いたときの情報が渡るか

## 用意したもの

| もの | 場所 |
|---|---|
| 試しのマーケットプレイス `hojokin-e4` | `experiments/E4/`（このフォルダ） |
| 試しのプラグイン `e4-probe` | `experiments/E4/e4-probe/` |
| 試しの会社のフォルダ（目印 `.hojokin/` あり） | `~/hojokin-e4/試しの会社/` |
| 目印のないフォルダ | `~/hojokin-e4/目印なし/` |
| hook のログ | `~/.hojokin-e4/hooks.jsonl`（場面ごと）、`~/.hojokin-e4/sh.log`（起動用の sh） |

試しの会社のフォルダは、リポの外に置いています。リポの下だと、このリポの CLAUDE.md が読み込まれ、本番の会社のフォルダと条件が変わるためです。

## 手順

### 1. プラグインを入れる

1. デスクトップアプリで、`~/hojokin-e4/試しの会社/` を作業フォルダにした新しいローカルのセッションを開く。
2. 「＋」→ Add plugins（または Plugins → Browse plugins）でプラグインの画面を開く。
3. マーケットプレイスを足す所があれば、`<このリポジトリ>/experiments/E4` を足す。
4. `e4-probe` を入れる。範囲は project（試しの会社）か local にする。user にはしない。user にすると、ほかのセッション（worktree のものを含む）でも hook が動くため。
5. 手元のフォルダを足す所がなければ、そこで止めて知らせてください。CLI で登録してよいかを、改めて伺います。

### 2. 開いたときの情報（SessionStart）

1. プラグインを入れたら、そのセッションを閉じ、`~/hojokin-e4/試しの会社/` で新しいセッションを開く。
2. 開いてから1分ほど待ってから、次を送る（モードは default）。

   > 合言葉と、それを受け取った時刻を教えてください。

3. 「さくら42」と時刻が返れば、情報が渡っています。

ログの SessionStart の時刻と、最初の UserPromptSubmit の時刻を比べます。SessionStart が開いたとき（送る1分前）に動いたか、送ったときに動いたかが分かります。

### 3. PreToolUse で拒めるか（default モード）

次を1つずつ送ります。

1. > Bash で `echo E4_DENY_JSON` を実行してください。結果をそのまま見せてください。
2. > Bash で `echo E4_DENY_EXIT2` を実行してください。結果をそのまま見せてください。
3. > Write で `メモ_v2.txt` というファイルに「試し」と書いてください。結果をそのまま見せてください。

拒まれ、理由の合言葉（もみじ7、いちょう3、かえで5）が Claude の応答に出れば、理由も Claude に届いています。

### 4. 同じことを auto モードで

モードを auto にして、手順3の1〜3をもう一度送ります。

### 5. Stop で差し戻せるか

> E4_STOP_TEST 今日の日付を一言で答えてください。

応答の最後に「差し戻しを受け取りました（つばき9）」が出れば、Stop hook が Claude を続けさせています。

### 6. 目印のないフォルダ

1. `~/hojokin-e4/目印なし/` で新しいセッションを開き、手順3の1を送る。
2. 拒まれずに動けば、目印のないフォルダで何もしない作りが効いています。

プラグインを project の範囲で入れた場合は、このフォルダでは hook が動きません（ログに出ない）。それも結果として残します。

## 終わったら

Claude がログを読み、項目ごとの結果を `experiments/E4/結果.md` と `experiments/結果.md` に書きます。試しが済んだら、プラグインを外します（Manage plugins）。
