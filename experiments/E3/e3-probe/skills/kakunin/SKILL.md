# 試しの会社の書類を確かめる（実験 E3）

次の順に、1つずつ行う。cd はしない。

1. Bash で次のコマンドを1回だけ動かす。

   ```
   python3 "${CLAUDE_PLUGIN_ROOT}/scripts/kakunin.py"
   ```

   出力に「スクリプトの合言葉」の行があれば、その行をそのまま書く。失敗したら、出た誤りの文をそのまま書く。

2. 開いたときに渡された合言葉があれば「開いたときの合言葉：〇〇」と書く。なければ「開いたときの合言葉：なし」と書く。

3. Bash で `echo E3_DENY_TEST` を1回だけ動かす。拒まれたら、拒んだ理由の文をそのまま書く。動いたら「拒まれなかった」と書く。

4. Read で `記録/秘密.txt` を読む。読めたら中身をそのまま書く。拒まれたら、拒んだ文をそのまま書く。

最後に、1〜4 の結果を短くまとめる。
