# AIらしくない自然な日本語のための基準（2026年11月2日の調査）

計画書の文体を確かめる基準です（F8、F9、T9-3、T9-3b）。平易な言葉はむしろ良く、避けたいのは「生成AIらしい言い回し」「難しすぎる文」「中身の薄い文」です。

根拠の強さを次の記号で示します。**公**＝公的な指針、**研**＝研究、**実**＝実務家の意見、**推**＝推測（根拠が弱い）。

## 調べて分かった大事な点

- **「AIらしい言い回し」の一覧は、裏付けが弱い。** ネット上の「AIらしさ」の指摘148件を実際の文章で確かめた調査では、当たっていたのは「読点が多い」の1点だけだった[3]。AIの下書き約25万字を調べた例では、「AIっぽい」と予想した34の表現のうち、実際に出てきたのは4つだけだった[7]。
- そのため、確認の中心は「具体的か」「審査員に伝わるか」に置き、言い回しの一覧は補助として使う。一覧は、このツールが実際に書いた文章を数えて見直していく。
- 体言止めは、人が書いた文章の方がむしろ多いという結果がある[3]。体言止めはAIらしさの目印にしない。
- 英語圏の研究[17][18]を日本語に当てはめた部分は推測にとどまる。

## A. 数えられる基準

「要修正」は直すまで完成としない。「注意」は一覧に出すだけで、直すかは社長が決める。

| 基準 | 目安 | 扱い | 根拠 |
|---|---|---|---|
| 一文の長さ | 60字を超えたら注意、100字を超えたら要修正 | 注意／要修正 | 公[1]「50〜60字ほどになったら意識する」（上限ではない）。実[9]の既定値は100字 |
| 文の長さのばらつき | 長さがそろいすぎている（極端に短い文も長い文もない） | 弱い注意 | 研[3]。ただし小規模な卒業論文で、計画書は長さがそろっていても問題ない |
| 一文の読点 | 4個以上 | 注意 | 実[9]、研[3]（AIの文は読点が多い） |
| 文末の繰り返し | 「しています」「できます」など同じ形が3文続く | 注意 | 実[11]（経験則）、研[3]。「ます」だけで数えると全文が当たるので数えない |
| 接続詞 | 同じ接続詞の連続。「また」「さらに」「これにより」の多さ | 注意 | 実[9][13][19]、研[3] |
| 「等」「など」「さまざまな」 | 1段落に2回以上 | 注意 | 公[1]「慎重に使う」。回数の目安は推 |
| 冗長な表現、二重否定、同じ助詞の連続、主語のない受身形 | 当てはまる箇所 | 注意 | 公[1]、実[9] |
| 漢字の連続 | 7字以上 | 注意 | 実[9] |
| 漢字の割合 | 4割を超える | 弱い注意 | 実（経験則で出典なし）、研[15][16]。専門用語の多い計画書では超えやすい |
| 定着していないカタカナ語 | 言い換えの一覧に当たる語 | 注意（言い換えの案を示す） | 公[1][2] |
| `**` や `##` などの記号の残り | 1つでもある | 要修正 | 実[14][19] |
| です・ます調とである調の混在 | 1つでもある | 要修正 | 公[1] |
| 具体性 | 数字・単位・固有名詞・期日が1つもない段落 | 審査員役のAIが個別に判定 | 推（公[1]の「幾つか→3点」と、[5]の数値の根拠を重んじる考えから） |

## B. 避ける言い回し

当たったときは言い換えの案と一緒に示します。社長が「自分の言葉なので残す」と決めたものは残してよいです。

| 区分 | 避ける表現 | 言い換えの例 | 根拠 |
|---|---|---|---|
| 硬すぎる | 喫緊の課題 | すぐ手を打つべき課題 | 公 |
| 硬すぎる | 可及的速やかに | できるだけ早く | 公 |
| 硬すぎる | 〜することができる | 〜できる | 公 |
| 硬すぎる | 調査を実施した | 調査した | 公 |
| 硬すぎる | 作業が進捗する | 作業がはかどる | 公 |
| 硬すぎる | 〜いたしております、ございます | 〜しています、です | 公 |
| 硬すぎる | 〜しないわけではない（二重否定） | 〜することもある | 公 |
| 硬すぎる | 導入が図られる（主語のない受身形） | 当社が〇月に導入する | 公 |
| 硬すぎる | 〜に資する、〜に鑑み | 〜に役立つ、〜を踏まえ | 推 |
| あいまい | 幾つか | 3点 | 公 |
| あいまい | 早期に | 2027年3月までに | 公 |
| あいまい | 大幅に、飛躍的に | 月40時間を10時間に | 公・実 |
| あいまい | 売上が伸び悩んでいる | 2025年度の売上は480万円で前年比15%減 | 実[12] |
| あいまい | さまざまな、多様な | 実際の対象を名指しする | 実[14] |
| あいまい | 〇〇等 | 代表例を挙げる | 公 |
| 中身が薄い | 革新的、画期的 | 従来のやり方とどこが違うかを書く | 実[12] |
| 中身が薄い | 多角的に | 「価格と納期の両面で」のように観点を示す | 実[14] |
| 中身が薄い | 最適化、活用 | 何をどう変えるかを書く | 実[14][19] |
| 中身が薄い | 効率化 | 1件40分を15分に | 実[19] |
| 中身が薄い | 付加価値の高い、高品質な | 単価や不良率で示す | 推 |
| 中身が薄い | 新たな価値を創出 | 何を誰に売るかを書く | 推 |
| 中身が薄い | 〜を実現します | 「〜できるようになる」に数字を添える | 推 |
| 中身が薄い | 包括的、抜本的 | 対象と範囲を書く | 推 |
| AIに多い定型 | 〜と言えるでしょう | 言い切って根拠を添える | 実[14] |
| AIに多い定型 | 〜が重要です（理由がない） | しないと何が起きるかを書く | 実[14][19] |
| AIに多い定型 | 近年〜が注目されています | 自社で起きた事実から書き出す | 実[19] |
| AIに多い定型 | 〜と言われています（出典がない） | 出典名と数値を書く | 実[8] |
| AIに多い定型 | このように（段落ごとの締め） | 削る | 実[13][19] |
| AIに多い定型 | 単なる〜ではなく、〜です（不要な対比） | 主張だけを書く | 実[6][8] |
| AIに多い定型 | これにより〜が可能になります | 「この機械で〜が減る」と書く | 実[13][19] |
| AIに多い定型 | 〜の鍵となる、中核を担う | 具体的な役割を書く | 実[8] |
| AIに多い定型 | 効率化・高品質化・省力化を実現（毎回3つ並べる） | 本当に効く1つに絞る | 実[8] |
| AIに多い定型 | 「品質で選ばれる。価格で勝つ。」（短い文や対句の連発） | 手順と理由をつなげて書く | 実[6] |
| 英語の直訳 | 解像度が上がる | 詳しく分かる | 実[7] |
| 英語の直訳 | 余白が生まれる | 空いた時間を〇〇に回す | 実[7] |
| 英語の直訳 | 伴走する、橋渡し | 月1回訪問して助言する | 実[7] |
| カタカナ語 | アジェンダ、サプライヤー | 議題、仕入先 | 公 |
| カタカナ語 | KPI | 目標数値（初めて出すときに説明する） | 公 |
| カタカナ語 | シームレスに | 途切れなく、一つの画面で | 推（言い換えの方針は公） |
| カタカナ語 | ソリューション、スキーム | 解決策、仕組み（中身を添える） | 推 |
| カタカナ語 | DX推進 | 受注をFAXから専用画面に変える | 推 |

定着したカタカナ語（パソコン、メールなど）はそのまま使ってよいです。

## C. 読んで判断する基準

審査員役のAI（T9-3b）と作者（T9-6）が確かめる観点です。業界の外の審査員に伝わるかを見るためのもので、書き方の型ではありません。書き手は観点をなぞって書かず、審査役も、観点の例と書き方が違っていても伝わっていれば可にします（11/7 の作者の方針。型が強く効くと、どの計画書も同じ形の文になるため）。

1. 各項目の冒頭に結論（何をするか）があるか［公］。段落ごとに同じ内容をまとめ直していないか［実］。最初の文を読めば分かればよく、「結論：」のような見出しは付けない（付けると全項目が同じ型に見える）。
2. 一文の論点が一つか［公］。
3. 抽象的な言葉に「具体的には？」と問いかけたとき、本文の数字・固有名詞・期日・担当者で答えられるか［公・実］。
4. 数値目標が願望ではなく、統計・アンケート・実績・見積に基づいているか［公[5]］。
5. 社名を他社に差し替えても通じる文になっていないか［推］。
6. 社長自身の言葉になっているか。現場の出来事、判断の理由、選ばなかった案が書かれているか［公[5]、実[14]］。
7. 課題 → 投資 → 効果の筋が通っているか［公[5]］。
8. 一番伝えたい点が分かるか。どの項目も同じ熱量、同じ型（定義 → 重要性 → 注意点）で並んでいないか［実[13][14]］。どの項目も同じ書き出し（「結論：」など）で始まっていたら不可。
9. 箇条書きを並列の情報だけに使っているか。理由や因果まで箇条書きで細切れにしていないか［公・実］。3項目以上なら箇条書きが勧められているので［公[1]］、数ではなく使い方を見る。
10. 業界の外の審査員でも、用語を説明なしで読めるか［公］。
11. 引用した統計や制度が実在するか（AIの作り話への対策）［推］。
12. 声に出して読んで、不自然なところがないか［実[13]］。前の文とつながらずに始まる短い文（「人が集まらない。」のような見出しの代わりの文）を段落の頭に置いて、事実を並べていないか。
