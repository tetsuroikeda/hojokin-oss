# デモ動画（ハッカソン提出用）

hojokin の紹介動画を、コードだけで作る道具です。映像・字幕・声・BGM を、すべてこのフォルダのスクリプトから作ります（音源や素材のファイルを持ち込みません）。プラグインには入りません。

- 長さ：約2分20秒（提出の条件は3分以内・日本語）
- 構成：中小企業が補助金でぶつかる5つの壁 → hojokin の紹介 → 壁ごとの解決（実物の出力） → PM のように自分から知らせる → 使うほど学習する → 守り → 終わり

## 何が実物か

動画に出す画面と文は、架空のデモの会社（株式会社やまぶき惣菜）で、実際にプラグインを動かして得たものです。

| 場面 | 出しているもの | どこから |
|---|---|---|
| 壁1 探す | 補助金の候補.docx | 保存した状態「1件目を終えた」の会社のフォルダ |
| 壁2 ルール | 概要と流れ.docx（出典のページつき）、公式資料のページ数（241） | 同上、downloads/shoryokuka_ippan の PDF |
| 壁3 書類 | 整理した後の原本の置き場、不備の一覧 | 対話/shorui.md（不備を仕込んだ書類14件を入れて「確認して」と頼んだ実際の応答） |
| PM | 「今日は何から？」への応答、今の状態.html | 対話/pm.md、会社のフォルダ |
| 壁4 書く | 財務モデル.xlsx、計画書 その1・2.docx、根拠対照表.xlsx、審査役の確かめる観点 | 会社のフォルダ、agents/shinsa.md |
| 壁5 採択後 | 今の状態.html の工程表、差し戻しの通知（架空の模擬画面） | 会社のフォルダ、testdata/計画書/材料/5_差し戻し |
| 学習 | 覚えた事実の数・書き方の決まり（社長が直した言い回し）・1件目の質問 | 記録/会社の記録.json、記録/質問の記録.json |

- 対話の文は、`素材.json` に写した引用が `対話/` の記録にそのままあるかを、build.py が確かめます（作り話の文を入れないため）。
- 壁1の社長の発言の吹き出しと、壁4の確かめの印（！→✓）の動きは、説明のための演出です。

## 作り方

1. デモの会社のフォルダを戻す（リポの根で）：
   ```bash
   /usr/bin/python3 -B evals/_lib/fukugen.py 1件目を終えた <作業用の空のフォルダ>
   ```
2. 開いたときの hook を一度動かし、今の状態.html を作る（Claude で開くか、hooks/run.sh SessionStart を流す）。
3. 道具を入れる（初回だけ。docs/video で）：`npm install`（puppeteer-core。この Mac の Google Chrome を使う）
4. 組み立てる（リポの根で）：
   ```bash
   uv run --with numpy python docs/video/build.py <作業用のフォルダ>
   ```
   出来たものは `docs/video/out/hojokin_demo.mp4`。`--no-video` を付けると、映像を撮らずに時刻表と音だけ作ります。

ほかに要るもの：ffmpeg、LibreOffice（soffice）、pdftoppm（poppler）、macOS の `say`（声は Kyoko）。

## ファイル

| ファイル | 中身 |
|---|---|
| 台詞.json | 場面ごとの台詞と、台詞の後の間。直すと時刻表も作り直される |
| 素材.json | 動画に出す実物の文（対話の引用、整理した後の置き場、書き方の決まり） |
| 対話/ | 実際の対話の記録（claude -p で流したもの） |
| video.html | 1コマを描くページ。`seek(t)` に秒を渡すと、その時刻の絵になる。ブラウザで開くと流れを確かめられる（`out/data.js` が要る） |
| build.py | 声 → 時刻表 → BGM → 映像 → 音を重ねる |
| make_bgm.py | BGM を numpy で作る（壁の場面は短調の持続音と刻み、本編は F–G–Em–Am の進行） |
| render.mjs | video.html を 30fps で撮って mp4 にする |
| stills.mjs | 確かめ用に、指定した秒の静止画を撮る |

声を人の声に差し替えるときは、`out/voice/<場面>.aiff` を録り直したものに置き換え、build.py の `make_voices` を飛ばしてください（時刻表は声の長さから作ります）。
