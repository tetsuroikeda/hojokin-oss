# タスクの一覧：補助金申請を自社で進めるための Claude Code プラグイン（仮称 hojokin-oss）

- SPEC.md と docs/DESIGN.md をもとに、作るときのタスクを並べた一覧です。要件と作り方の正本は SPEC と DESIGN です。食い違ったらそちらに従い、この一覧を直します。
- 1つのタスクは、1つのセッションか1回の `/goal`（1時間ほど）で作って確かめられる大きさにしています。
- 「終わりの確かめ」は、そのまま `/goal` の完了条件に使えます。`/goal` の判定役は会話しか読まないので、どれも「〜の出力を会話に示す」の形にしています。
- SPEC のテストは100件（T9-3b を含む）です。どれも、いずれかのタスクの「終わりの確かめ」に入っています（11章）。

## 2. 読み方

- 状態は「まだ」か「済み」。タスクを終えたら「済み」に直し、そのタスクのコミットに含める。
  - worktree で並べて進めるセッションは、状態の欄も `experiments/結果.md` も直さない。実験の結果は `experiments/E<番号>/結果.md` に書く。
  - worktree のブランチを日のブランチにまとめ、状態の欄と `experiments/結果.md` を直すのは、日のブランチのセッション（CLAUDE.md）。
- 「先に済ませるタスク」がすべて済んだものから始める。
- `uv run pytest <ファイル>` は自動のテスト（SPEC 6章）。
  - `tests/test_T*.py` は、SPEC のそのテストの合格ラインを1つ残らず確かめる形で書く。
  - テストを書いたセッションが、そのまま通すことになる。そのため、コミットの前に spec-check（R3）が、テストが合格ラインを満たしているかを照らす。
- 「eval（タグ F5）」は、SPEC 6章の振る舞いテストのコマンドに、`--tag F5 --runs 1 --ablation none --max-cost-usd <上限>` を付けて流すこと（DESIGN 12章）。
  - タグは機能の番号にする。共通の要件は F0、skill の選ばれ方は skill。
  - 作っている間は1回ずつ流す。SPEC の合格ライン（3回とも合格）は、R5・R6 で確かめる。
  - 審査役が判定するテスト（T8-8、T8-9、T9-3b、T13-6、T13-9 など）は、審査役の結果に判定と理由があるかだけでなく、判定の中身が SPEC の合格ライン（「切れ目0件」など）を満たすかで合否を見る。
- 作者の判断が要るものは、作者のタスク（A）に切り出してある。作業のセッションは、その判断を自分で決めずに、A のタスクを待つ。
  - ただし 11/5 からは、作者の方針（デモを動かすことを第一にし、人の承認はできる限りなくす）で、A2・A3・A16 の作者の確かめと、A4・A6・A7 は待たない。どう進めるかは、8章の各行と、それを待っていた行（D3、D10、B21、B23、B25）に書いた。
- コマンドの全文は10章にある。

## 10. コマンド

| 略した書き方 | コマンド |
|---|---|
| 構成の検査 | `claude plugin validate . --strict` |
| 自動のテスト | `uv run pytest tests/<ファイル>` |
| eval（タグ X） | `claude plugin eval . --scaffold --trust-plugin --allow-tools Bash Write Edit --threshold 1.0 --json --tag X --runs 1 --ablation none --max-cost-usd <上限>` |
| Δ | 上の eval から `--runs 1 --ablation none` を外し、`--ablation with-without` を付ける |
| 3回の実行 | 上の eval から `--runs 1` を外す（ケースのファイルに runs を書かなければ、1ケースを3回流す） |

テスト番号が、どれかのタスクの「終わりの確かめ」に入っているかは、次のコマンドで確かめます。何も出なければ、抜けも打ち間違いもありません。左に出た番号は、どのタスクにも入っていないもの、字下げして出た番号は SPEC にない番号です。

```bash
comm -3 <(grep -oE '^\| T[0-9]+-[0-9]+b? [^|]*\| (自動|振る舞い|構成|人)' SPEC.md | grep -oE 'T[0-9]+-[0-9]+b?' | sort -u) <(grep -E '^\| [A-Z][0-9]+[a-z]? \|' docs/TASKS.md | awk -F'|' '{print $5}' | grep -oE 'T[0-9]+-[0-9]+b?' | sort -u)
```
