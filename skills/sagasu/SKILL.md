# 補助金を探す・決める（F1、F2）

## 最初に目印を確かめる

- 最初に、今のフォルダに `.hojokin/`（会社のフォルダの目印）があるかを確かめる。
- 目印がなくても、補助金を探して説明することはしてよい。会社のフォルダでないフォルダで動いてよいのは、探すことと、会社のフォルダを作ることだけ。
- 探した結果をファイルに残す前に、目印がなければ「このフォルダを〇〇社の会社のフォルダにしますか」と社長に聞く。了承を得るまで、フォルダに何も書かない。

## 探す

目的は、社長の会社に合う補助金・助成金を、出典つきで漏れなく並べること。進め方は任せる。

1. **聞き取る**：業種、所在地、従業員数、やりたいこと、時期、予算を聞く。会社の記録と手元の書類で分かることは聞かない。答えに応じて次の質問を変える。質問は選択肢の画面（AskUserQuestion）で1問ずつ、勧める案と「分からない」を入れ、聞く理由を一言添える。
2. **集める**：次のすべてから集める。
   - jGrants の公開API（下の道具）。言葉を替えて何度か探してよい。
   - 例年公募がある国の制度（省力化投資補助金、小規模事業者持続化補助金など）の公式サイト。
   - 所在地の都道府県・市区町村のサイト（その都度 Web で調べる）。厚生労働省の助成金も候補にする。
   - 予算の状況（国は当初予算・補正予算・概算要求、自治体は予算の公表資料）。見つからなければ「見つからなかった」と書き、推測しない。
3. **分ける**：「公募中」「公募予定（発表済み）」「例年公募がある」の3つに分ける。例年公募があるものは、過去の公募の時期（直近2回以上）から次の公募を見込み、時期と根拠を書く。
4. **示す**：候補ごとに、合う理由、対象外になりそうな点、次の公募の見込み、予算の状況、出典URL を会話で示す。要件を明らかに満たさない制度は外すか、「対象外の可能性が高い」と明記する。**出典を示せない制度は出さない。**
5. **Word に残す**：目印があれば（なければ了承を得て会社のフォルダを作ってから）、下の道具で「補助金の候補.docx」を作る。探し直したときも、同じ道具で同じファイルを直す。Write・Edit で Word を書かない。

### jGrants の検索の道具

```bash
python3 -B "${CLAUDE_PLUGIN_ROOT}/skills/sagasu/scripts/jgrants_search.py" --keyword 省力化
```

- 必須の検索条件（言葉・並べ方・順番・受付中かどうか）は道具がいつも付ける。言葉は2文字以上。
- 任意の条件：`--industry`（業種）、`--employees`（従業員数）、`--area`（地域）、`--use-purpose`（利用目的）。受付中でないものも見るときは `--all`。
- 締切と受付開始は、日本時間で出る。社長に示すときも、この日本時間の表示をそのまま使う（自分で時刻を直さない）。
- 出典URL は jGrants の補助金のページ。省力化・持続化の今の回は jGrants に出ないことがあるので、公式サイトでも確かめる。
- 終了コード1（つながらない）のときは、ほかの集め方で候補を集め続け、「jGrants は確かめられなかった」と社長に伝える。

### 補助金の候補.docx の道具

候補の一覧を JSON で標準入力に渡す（会社のフォルダの直下の「補助金の候補.docx」だけを書く）。

```bash
python3 -B "${CLAUDE_PLUGIN_ROOT}/skills/sagasu/scripts/kouho_word.py" --folder "${CLAUDE_PROJECT_DIR}" <<'EOF'
{
  "会社名": "〇〇株式会社",
  "聞き取りの要点": ["惣菜の製造", "盛り付けと包装を機械にしたい"],
  "候補": [
    {
      "名前": "中小企業省力化投資補助金（一般型）",
      "区分": "例年公募がある",
      "合う理由": "…",
      "対象外になりそうな点": "…",
      "次の公募の見込み": "…（時期と根拠）",
      "予算の状況": "…（出典つき。見つからなければ「見つからなかった」）",
      "出典URL": ["https://…"],
      "締切": "（公募中なら、道具が出した日本時間の締切）",
      "対象外の可能性が高い": false
    }
  ]
}
EOF
```

- 区分は「公募中」「公募予定（発表済み）」「例年公募がある」のどれか。「締切」と「対象外の可能性が高い」のほかは、すべて必須。
- 文字の欄は、文字か文字の並び（箇条書きになる）。
- 欠けた欄や出典のない候補があると、何も書かずに直す所を返す（終了コード2）。直して、もう一度流す。

## 決める

目的は、社長が「申請するか」を、要件・義務・返還の条件を知ったうえで決められるようにすること。

- 社長が制度を選んだら、その制度の公募要領を読む。手元になければ公式サイトの公募要領を Web で読む（会社のフォルダに取り込んで制度データにするのは、決めた後の junbi）。
- 次を一覧（表）で示す。どの行にも、資料名・ページ・URL を付ける。資料に書かれていないことは「資料には書かれていません」と書き、推測で埋めない。
  - 要件（申請できる会社、数値の要件など）
  - 義務（賃上げ、効果報告の期間、書類を残す期間、処分の制限など）
  - 返還の条件（どんなときに、いくら返すか）
  - 日程（締切、事業の期間）と、自己負担額の目安
- 同じ経費を別の補助金にも計上していないか（二重受給）を社長に確かめる。
- 要件を満たせない見込みなど、申請しない方がよいときは、理由を添えてはっきり伝える。進めるかは社長が決める。
- 決まったら、junbi で案件の準備に進むことを案内する。
