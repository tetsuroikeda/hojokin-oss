# 補助金を探す・決める（F1、F2）

## 最初に目印を確かめる

- 最初に、今のフォルダに `.hojokin/`（会社のフォルダの目印）があるかを確かめる。
- 目印がなくても、補助金を探して説明することはしてよい。会社のフォルダでないフォルダで動いてよいのは、探すことと、会社のフォルダを作ることだけ。
- 探した結果をファイルに残す前に、目印がなければ「このフォルダを〇〇社の会社のフォルダにしますか」と社長に聞く。了承を得るまで、フォルダに何も書かない。

## 道具の動かし方（どの手順にも共通）

- 社長の答えを受けて続けるとき（新しい発言のたび）、会話を開き直した後は、道具を動かす前にこの skill を呼び直す（呼び直さないと、道具が確かめの画面で止まることがある）。
- 道具に渡す JSON は、Write で `記録/一時/<決まった名前>.json` に置き、その場所を `--input` で渡す。標準入力（`<<'EOF'`）では渡さない（会社のフォルダの設定で、確かめの画面が出るため）。ファイルは消さず、同じ名前で上書きする。
- その場の計算のコードが要るときも `記録/一時/` に置く。`python3 -c`・パイプ・sed は使わない。

## 探す

目的は、社長の会社に合う補助金・助成金を、出典つきで漏れなく並べること。進め方は任せる。

1. **聞き取る**：業種、所在地、従業員数（正社員とパートの内訳）、やりたいこと、時期、予算を聞く。会社の記録・手元の書類・社長の発言で分かることは聞かない。答えに応じて次の質問を変える（例：機械を入れたいなら金額と時期、人を増やす・正社員にするなら人数と時期）。
   - 質問は選択肢の画面（AskUserQuestion）で1問ずつ、勧める案と「分からない」を入れ、聞く理由を一言添える。
   - 選択肢の画面が使えないときは、普段の文で「【質問】」と書き、続けて番号・問い・「（理由：…）」の形で**3つまで**並べる（多いときは、聞きたいことの一覧を先に見せてから、3つずつ聞く）。答えを待ってから探す。
   - 社長が「聞かずに探して」と言ったときや、探すのに足りることが分かっているときは、聞かずに探してよい（分からない所は、候補の「対象外になりそうな点」に書く）。
2. **集める**：次のすべてから集める。
   - 同梱の「例年公募がある制度の一覧」（下の道具）。国の補助金と厚生労働省の助成金の、公式サイト・これまでの公募の日付と出典・対象の目安・予算の調べ先が出る。**最初に必ず流す。**
   - jGrants の公開API（下の道具）。言葉を替えて何度か探してよい。
   - 一覧の制度の公式サイト（今の公募を確かめ直す。一覧は確かめた日の記録なので）。
   - 所在地の都道府県・市区町村のサイト（その都度 Web で調べる）。厚生労働省の助成金も、会社の人の動き（正社員にする、賃金を上げる、研修を受けさせる）に合うものを候補にする。
   - 予算の状況（国は当初予算・補正予算・概算要求、自治体は予算の公表資料）。一覧の「予算の調べ先」から調べる。見つからなければ「見つからなかった」と書き、推測しない。
   - 通信できない（Web の道具がない、jGrants が終了コード1）ときは、一覧の記録で候補を作り続け、確かめられなかったものと、その理由を社長に伝える。所在地の自治体の制度が調べられなかったときも、そう伝える。
3. **分ける**：「公募中」「公募予定（発表済み）」「例年公募がある」の3つに分ける。日付の比べは自分でせず、一覧の道具の「今日の区分の目安」を使う（公式サイトで今の公募を確かめられたら、その結果で直す）。
   - 例年公募があるものは、過去の公募の時期（**直近2回以上**。一覧の「これまでの公募」「前の制度」の日付）を「次の公募の見込み」に書き、そこから次の公募の時期を見込む（時期と根拠）。
   - 目安が「確かめが要る」で、公式サイトでも今の受付を確かめられなければ、過去の公募の時期が2回以上分かるものは「例年公募がある」に入れ、「次の公募の見込み」に「今の受付は確かめられなかった（わけ）」と過去の時期を書く。
   - 今の受付も、過去の公募の時期（2回以上）も確かめられない制度は、区分を決められないので、候補の一覧（Word）には入れない。会話で「確かめられなかった制度」として、名前・公式サイト・確かめられなかったわけを伝える（推測で日付や区分を作らない）。
4. **対象外を見分ける**：要件を明らかに満たさない制度（例：持続化は、常時使用する従業員の数が業種ごとの上限を超えると申請できない。一覧の「対象の目安」）は、外すか、「対象外の可能性が高い」を true にして、どの要件に当たらないかを「対象外になりそうな点」に書く。会話でも「対象外」とはっきり伝える。
5. **示す**：候補ごとに、合う理由、対象外になりそうな点、次の公募の見込み、予算の状況、出典URL を会話で示す。**出典を示せない制度は出さない。**
   - 「予算の状況」は1つの文にし、出典の URL を文の中に書くか、「見つからなかった」と書く（どちらもないと、採点でも社長にも、確かめた所が分からない）。
6. **Word に残す**：目印があれば（なければ了承を得て会社のフォルダを作ってから）、下の道具で「補助金の候補.docx」を作る。探し直したときも、同じ道具で同じファイルを直す。Write・Edit で Word を書かない。

### 例年公募がある制度の一覧の道具

```bash
python3 -B "${CLAUDE_PLUGIN_ROOT}/skills/sagasu/scripts/reinen.py" --folder "${CLAUDE_PROJECT_DIR}"
```

- 何も書かない。会社のフォルダでなくても動く（今日の日付は、会社のフォルダなら差し替えた日付を使う）。
- `--name 持続化` のように、名前か略称の一部で絞れる。`--json` で JSON。
- 所在地の自治体の制度は入っていない（その都度調べる）。

### jGrants の検索の道具

```bash
python3 -B "${CLAUDE_PLUGIN_ROOT}/skills/sagasu/scripts/jgrants_search.py" --keyword 省力化
```

- 必須の検索条件（言葉・並べ方・順番・受付中かどうか）は道具がいつも付ける。言葉は2文字以上。
- 任意の条件：`--industry`（業種）、`--employees`（従業員数）、`--area`（地域）、`--use-purpose`（利用目的）。受付中でないものも見るときは `--all`。
- 締切と受付開始は、日本時間で出る。社長に示すときも、この日本時間の表示をそのまま使う（自分で時刻を直さない）。
- 出典URL は jGrants の補助金のページ。省力化・持続化の今の回は jGrants に出ないことがあるので、公式サイトでも確かめる。
- 終了コード1（つながらない）のときは、ほかの集め方で候補を集め続け、「jGrants は確かめられなかった」と社長に伝える。

### 補助金の候補.docx の道具

候補の一覧の JSON を Write で `記録/一時/補助金の候補.json` に置き、道具に渡す（会社のフォルダの直下の「補助金の候補.docx」だけを書く）。

```bash
python3 -B "${CLAUDE_PLUGIN_ROOT}/skills/sagasu/scripts/kouho_word.py" --folder "${CLAUDE_PROJECT_DIR}" --input 記録/一時/補助金の候補.json
```

```
{
  "会社名": "〇〇株式会社",
  "聞き取りの要点": ["惣菜の製造", "盛り付けと包装を機械にしたい"],
  "候補": [
    {
      "名前": "中小企業省力化投資補助金（一般型）",
      "区分": "例年公募がある",
      "合う理由": "…",
      "対象外になりそうな点": "…",
      "次の公募の見込み": "…（時期と根拠。例年公募があるものは、過去の公募の時期を直近2回以上）",
      "予算の状況": "…（出典の URL を文に入れる。見つからなければ「見つからなかった」）",
      "出典URL": ["https://…"],
      "締切": "（公募中なら、道具が出した日本時間の締切）",
      "対象外の可能性が高い": false
    }
  ]
}
```

- 区分は「公募中」「公募予定（発表済み）」「例年公募がある」のどれか。「締切」と「対象外の可能性が高い」のほかは、すべて必須。
- 文字の欄は、文字か文字の並び（箇条書きになる）。
- 欠けた欄や出典のない候補があると、何も書かずに直す所を返す（終了コード2）。直して、もう一度流す。

## 決める

目的は、社長が「申請するか」を、要件・義務・返還の条件を知ったうえで決められるようにすること。

- 社長が制度を選んだら、その制度の公募要領を読む。手元になければ公式サイトの公募要領を Web で読む（会社のフォルダに取り込んで制度データにするのは、決めた後の junbi）。
- 次を一覧（表）で示す。どの行にも、資料名・ページ・URL を付ける。資料に書かれていないことは「資料には書かれていません」と書き、推測で埋めない。
  - 要件（申請できる会社、数値の要件など）
  - 義務（賃上げ、効果報告の期間、書類を残す期間、処分の制限など）
  - 返還の条件（どんなときに、いくら返すか）
  - 日程（締切、事業の期間）と、自己負担額の目安
- 同じ経費を別の補助金にも計上していないか（二重受給）を社長に確かめる。
- 要件を満たせない見込みなど、申請しない方がよいときは、理由を添えてはっきり伝える。進めるかは社長が決める。
- 決まったら、junbi で案件の準備に進むことを案内する。
