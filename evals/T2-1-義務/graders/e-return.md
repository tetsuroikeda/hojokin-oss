返還の条件（8件）。「返還」は、返金・返す・返し（言い換え）でもよい。

| 正解の id | 返還の条件 | 探す語 |
|---|---|---|
| G30 | 財産を処分したら残存簿価か時価で納付 | 残存簿価・帳簿価格・時価・納付（納める） |
| G35 | 1人当たり給与支給総額の目標が未達なら返還 | 給与と返還（200字以内） |
| G36 | 事業場内最低賃金が地域別+30円に届かない年は返還 | 最低賃金と返還（同じ行） |
| G37 | 大幅賃上げ特例で+6.0%が未達なら引き上げ額を返還 | 6.0% |
| G38 | 大幅賃上げ特例で事業場内最低賃金+50円に届かなければ返還 | 50円 |
| G39 | 効果報告を出さない・虚偽なら返還を求められる | 効果報告（報告しない・虚偽の報告）と返還（同じ行） |
